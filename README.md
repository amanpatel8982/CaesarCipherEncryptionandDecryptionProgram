# 🔐 Caesar Cipher - Encryption & Decryption Program

This is a simple and interactive **Caesar Cipher** program developed in **Python**, allowing users to securely **encrypt** or **decrypt** messages using a shift value. The Caesar Cipher is a classic technique in cryptography where each letter in the message is shifted by a fixed number of positions in the alphabet.

---

## 📌 Features

- ✅ Encrypt or decrypt messages using Caesar Cipher
- 🔢 Accepts shift values from 0 to 25
- 🔠 Supports both uppercase and lowercase letters
- 🧾 Non-alphabetic characters remain unchanged
- 🔁 Interactive and user-friendly command-line interface

---

## 🧠 How It Works

1. Choose mode: `encrypt` or `decrypt`
2. Enter your message
3. Provide a valid shift key (0–25)
4. Get the encrypted or decrypted result instantly!
